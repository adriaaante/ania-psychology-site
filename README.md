# Анна Маловичко — сайт психолога

Премиальный сайт-визитка психолога Анны Маловичко (Пятигорск и онлайн).
**Статический сайт без сборки**: чистый HTML5 + CSS (custom properties) +
Vanilla JS. Нет npm, нет бандлера, нет бэкенда (кроме одного PHP-файла для
истории сертификатов). Открывается двойным кликом по `index.html`.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: hero, запросы, услуги, этапы, отзывы, FAQ, контакты |
| `about.html` | Обо мне: история, образование (таймлайн), дипломы, ценности |
| `services.html` | Услуги и цены, форматы (очно/онлайн) |
| `contacts.html` | Контакты + карта |
| `404.html` | Страница ошибки |
| `gift.html` | Просмотр подарочного сертификата (по ссылке, `noindex`) |
| `gift-studio.html` | Закрытая студия сертификатов Анны (пин-код, `noindex`) |
| `gift-api.php` | История сертификатов на хостинге (единственный PHP-файл) |

## Как править контент

- **Контакты, адрес, цены, фамилия** — `assets/js/config.js`
  (единственный источник правды, все страницы подхватывают автоматически).
  Если Анна сменит фамилию — поменять там + `<title>`/meta в HTML-страницах
  и перегенерировать обложку (`python3 scripts/generate-og.py`).
- **Палитра** — `assets/css/styles.css`, блок `:root` (шалфей + карамель + крем).
- **Фото Анны** — положить файлы:
  - `assets/img/anna/hero.jpg` (портрет ~4:5, главная);
  - `assets/img/anna/about.jpg` (страницы «Обо мне» и превью).
  Пока файлов нет, показываются SVG-плейсхолдеры с монограммой (fallback
  через `onerror`) — после добавления JPG всё подхватится само.
- **Дипломы** — сканы в `assets/img/diplomas/`, затем в `about.html` заменить
  карточки-плейсхолдеры на `<div class="diploma-card"><img src="..."></div>`.
  Данные таймлайна образования на странице — **образец**, заменить на реальные.
- **Отзывы, цифры (часы практики и т.п.)** — образцы, поправить в HTML на реальные.

## Подарочные сертификаты

Все данные сертификата зашиты в ссылку: `gift.html#1.<base64url(JSON)>`.
- Студия: открыть `gift-studio.html`, пин-код **1234** (4 цифры).
  Пин хранится в коде как `atob('MTIzNA==')` — защита символическая, страница
  не индексируется и с сайта на неё нет ссылок.
- Смена пина: поменять base64 в `gift-studio.html` **и** `PIN_HASH` в
  `gift-api.php` (`echo -n 'НОВЫЙ_ПИН' | sha256sum`).
- История выданных сертификатов хранится на хостинге (`gift-api.php` →
  `gift-data/history.json`). При деплое **не удалять папку `gift-data`**.
  Без PHP-хостинга студия работает тоже — история останется в браузере.

## Локальный запуск

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Деплой

Сборки нет — заливается репозиторий как есть (кроме `scripts/`, `*.md`).
Подойдёт любой статический хостинг; для общей истории сертификатов нужен
хостинг с PHP (например, reg.ru). Домен пока не подключён: в `robots.txt`
и `sitemap.xml` стоит плейсхолдер `annamalovichko.ru` — заменить на реальный.
